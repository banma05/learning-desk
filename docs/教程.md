# 教程

从装好到用顺手，按顺序看就行。

## 一、安装

需要：Python 3.10 或更新、git、[Claude Code](https://claude.com/claude-code)。

```bash
git clone https://github.com/banma05/learning-desk.git
python learning-desk/install.py D:/我的知识库
```

`D:/我的知识库` 换成你想放知识库的地方，这个文件夹要么还不存在，要么是空的；路径里不能有 `#`。安装时会问：

```
这个知识库主要用来做什么？[1] 自学  [2] 工作上手、了解项目
```

- **自学**：问题表不分"问谁"，没有工作表。
- **工作上手、了解项目**：问题表按"自己 / 同事 / 上级"分列，多一张工作表，记需求、排查这些真实的工作。

不想被问，可以直接加 `--use study` 或 `--use work`。

安装脚本做了这几件事：

1. 把 `模板/` 和 `工具/` 复制进知识库文件夹，在里面建一个 git 仓库，做第一次提交。这个仓库**没有远程**，只在你的电脑上。
2. 在 Claude Code 的设置文件 `~/.claude/settings.json` 里加两个钩子，并允许 Claude 编辑这个文件夹。
3. 在 `~/.claude/CLAUDE.md` 末尾加一行 `@D:/我的知识库/维护约定.md`，让每个会话都读到维护约定。
4. 生成一次网页。

改设置文件之前会先备份，备份文件名形如 `settings.json.bak-20260105-093000`。想先看会改什么、什么都不写，加 `--dry-run`。

装好后终端会打印：

```
学习台知识库建好了：D:\我的知识库
- 双击 D:\我的知识库\学习台.html 看网页
- 新开一个 Claude Code 会话，先请 Claude 帮你填好 维护约定.md 第一节"我是谁"
- 以后在任何项目里和 Claude 聊，它都会按约定把学到的东西记进来
```

如果你的电脑还没告诉过 git 你是谁，会多一段提示，照着运行两条 `git config` 就好。

## 二、第一次对话

新开一个 Claude Code 会话（在哪个项目里开都行）。会话开始时，钩子会告诉 Claude 知识库在哪、今天的计划建了没有。

1. **填"我是谁"**：说"帮我填一下维护约定的第一节"，Claude 会问你的背景、在学什么、希望讲到什么程度，再写进 `维护约定.md`。讲法有不喜欢的，直接让它改第一节下半部分的"默认讲法"。
2. **搭第一张地图**：说"我要开始学 ××，先帮我搭项目地图"。Claude 会建 `项目/××/骨架.md`，把这个项目分成几大块，碰过的挂上笔记，没碰过的留空。
3. 之后每次 Claude 往知识库里写了东西，回答末尾都会有一行，例如 `已记录：概念/幂等（新建）、问题 T1`。

## 三、一天怎么用

- **早上**：当天第一次对话时，Claude 会先补齐前一天缺的日志，再参考前一天的复盘和总计划的进度表，起草今天的计划（`计划/YYYY-MM-DD.md`），你可以当场改。
- **白天**：照常学、照常干活。弄懂一个点，Claude 补笔记或概念卡；卡住了，进问题表；计划里的事做完了，它就勾掉。
- **晚上**：说"今天到这儿"，Claude 会写复盘（完成几项、没完成的为什么、明天怎么调），再补"搞懂了""卡在哪里"。

想做长一点的规划，就和 Claude 一起填 `计划/总计划.md`：目标、检查节点，再加一张每周一行的进度表。会话开始时，Claude 会读到这一周那一行。

## 四、网页怎么看

双击知识库里的 `学习台.html`，断网也能打开。左边是导航：

- **项目**：每个项目一张地图，每个大块显示掌握了多少；点进去是知识图谱和笔记。
- **概念**：跨项目通用的概念卡。
- **计划**：左边是总计划，右边是每天的记录，默认只展开"今日计划""要点""复盘"。
- **工作**：只有工作用途才有。
- **成果**：做过的东西，只放入口。
- **问题**：待解决的问题，工作用途按"问谁"分列；已解决的按所属归组。

左上角可以搜知识点、笔记和表名。格式写得不对时，页面顶部会列出"格式提示"，让 Claude 修就行。

在知识点上改掌握程度（已掌握 / 学习中 / 没碰）：在 Chrome 或 Edge 里，第一次会让你选一下知识库文件夹，之后点一下就直接写回文件；其他浏览器会复制一句话，粘给 Claude 让它改。

## 五、想改规则

- **讲法、记录规则**：直接改知识库里的 `维护约定.md`，下一个会话就按新的来。
- **设置**：改 `学习台配置.json`：
  - `问谁`：问题表的分列，比如 `["自己", "同事", "导师"]`；写成 `[]` 就不分。
  - `问题编号前缀`：比如 `{"T": "技术", "B": "业务"}`，问题编号就是 T1、B1 这样续下去。
  - `代码根目录`：笔记可以链接到这个目录下的文件，默认是知识库的上一级。
- **从自学换成工作用途**：配置里 `问谁` 写上 `["自己", "同事", "上级"]`；问题表在"所属"和"怎么查"之间加一列"问谁"，已有的行补上；从 `模板/` 复制一份 `工作.md` 进知识库。反过来就是删掉这一列和 `工作.md`，`问谁` 改成 `[]`。

## 六、常见问题

**会话开始时 Claude 不知道知识库在哪？**
钩子没生效。确认 `~/.claude/settings.json` 里有 `session_start.py` 那一项，然后重开 Claude Code。换过 Python 的话，对同一个知识库再运行一次 `install.py`：已有的知识库不会重建，只把钩子重新接上，换成现在的 Python。挪过知识库文件夹的话，先用**旧路径** `--uninstall`，再对新路径运行一次 `install.py`。

**换了一台电脑？**
把知识库同步过去（比如从你自己的私有仓库 clone 下来），再对那个文件夹运行一次 `install.py`，就会接到这台电脑的 Claude Code 上。

**网页没更新？**
只有 Claude 用编辑工具改的文件才会触发重新生成。你自己手改的话，运行一次 `python 工具/build.py`。生成出错时，原因记在知识库的 `工具/hook.log` 里。

**自动提交失败？**
`工具/hook.log` 里有一行 `commit failed for …`，后面是 git 的原话。最常见的是 git 还不知道你是谁：运行两条 `git config --global` 设置名字和邮箱。

**怎么更新？**
在克隆下来的仓库里 `git pull`，再运行：

```bash
python learning-desk/install.py --update D:/我的知识库
```

只换知识库里的 `工具/`，笔记和配置都不动。

**怎么卸载？**

```bash
python learning-desk/install.py --uninstall D:/我的知识库
```

只把钩子、权限和导入那一行从 Claude Code 设置里去掉（同样先备份），知识库文件夹原样留着，不要了就自己删。

**为什么不要把知识库推到公开仓库？**
里面是你和 Claude 聊出来的东西，工作上手时难免记下项目名、表名、同事的名字。知识库默认没有远程，就是为了防止误推。想在几台电脑之间同步，推到只有你自己能看的私有仓库。
